# KUDO Севастополь

Сайт спортивного клуба KUDO в Севастополе на Next.js 15.

## Технологии

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS 3**
- **Swiper**

## Установка и запуск

```bash
npm install
npm run dev
npm run build
npm run start
```

## Структура

```
app/           # App Router (страницы, layout)
components/    # Переиспользуемые компоненты
public/        # Статика (шрифты, изображения, видео)
```

## Страницы

| Маршрут      | Описание       |
|--------------|----------------|
| `/`          | Главная        |
| `/parents`   | Для родителей  |
